# Quantum-Tunneling
This code is a quantum physics calculator and visualizer. It helps you study quantum tunneling—a phenomenon where tiny particles (like electrons) can pass through a physical barrier even if they don't have enough energy to go over it.
This Python script, quantum_tunneling_solver.py, is a computational and visual tool designed to solve and analyze the quantum mechanical problem of a particle tunneling through a 1D rectangular potential energy barrier.   Below is a detailed breakdown of its architecture, physical principles, and outputs:1. Physical Principles & FormulasThe script models a particle of mass $m$ and energy $E$ incident on a potential barrier of height $V_0$ and width $L$:Wave Number ($k$): Represents the spatial frequency of the wave function in the free-particle regions ($x < 0$ and $x > L$):
$$k = \frac{\sqrt{2mE}}{\hbar}$$Decay Constant ($\kappa$): Represents the exponential attenuation (evanescent wave) inside the barrier region ($0 \le x \le L$ when $E < V_0$):
$$\kappa = \frac{\sqrt{2m(V_0 - E)}}{\hbar}$$Transmission Coefficient ($T$): The exact quantum mechanical probability of the particle tunneling through the barrier:
$$T = \frac{1}{1 + \frac{V_0^2 \sinh^2(\kappa L)}{4E(V_0 - E)}}$$Reflection Coefficient ($R$): The probability that the particle is reflected:
$$R = 1 - T$$2. Key Code ComponentsParameter Configuration: Defines physical constants ($\hbar$, electron charge, and particle masses for electrons and protons) and sets default parameters ($E = 1.0\text{ eV}$, $V_0 = 2.0\text{ eV}$, $L = 0.5\text{ nm}$).Numerical Calculation: Converts all units into standard International System of Units (SI) and evaluates $k$, $\kappa$, $T$, and $R$.Console Output: Prints a formatted summary table displaying input parameters, calculated wave numbers, and exact transmission/reflection probabilities (and percentages).Visualization & Plotting (matplotlib):Figure 1: Plots the 1D rectangular potential barrier $V(x)$ alongside an illustrative visual model of the wave function $\psi(x)$ across all three regions (incident, evanescent decay, and transmitted wave).Figure 2: Plots a logarithmic curve (semilogy) of the Transmission Probability vs. Barrier Width ($L$), highlighting how exponentially sensitive quantum tunneling is to changes in barrier thickness.3. Default Execution Summary (Electron Example)When executed with default parameters ($1\text{ eV}$ electron against a $2\text{ eV}$, $0.5\text{ nm}$ barrier), the script computes:Wave number ($k$) / Decay constant ($\kappa$): $5.1232 \times 10^9\text{ m}^{-1}$Transmission Probability ($T$): $2.3828 \times 10^{-2}$ ($\approx 2.38\%$)Reflection Probability ($R$): $0.9762$ ($\approx 97.62\%$)
